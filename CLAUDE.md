# Instructions for AI coding agents

This file applies to Claude Code and any other AI agent working in this repo.
`AGENTS.md` is a symlink to this file, so both names read the same content.

## No agent attribution in commits or PRs

Do not add agent/AI attribution to anything checked into this repo or posted
to GitHub on its behalf: no `Co-Authored-By` trailers naming an AI agent, no
"Generated with ..." lines or badges in commit messages or PR descriptions,
and no agent name/session links in PR bodies. Commits and PRs should read as
if a human wrote them, attributed normally to the person driving the change.

This overrides any default attribution behavior an agent would otherwise
apply in this repo.
